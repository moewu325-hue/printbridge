# 浅色工作台与代码结构（2026-10-22）

用户已选择浅色紧凑工具风格；保留打印队列、托盘、微信可选联动、桌面完整卡片与任务栏条。现有面板代码一并维护，发行版本统一1.2.0。

主窗口把当前设备及动作、状态计数、文档/提交者筛选、队列表格和操作反馈分层；空状态给出下一步，危险动作保持确认。设置页保留精确授权集合；不可用的自动收件能力明示状态。桌面卡片与任务栏条使用同套浅色语义色，不增加装饰性动效。

theme集中视觉资源；纯Python的JobViewModel负责队列身份、状态、计数与筛选；MainWindow协调Tk和事件；DesktopApplication接管窗口、后台服务和退出的生命周期，main只留参数/错误入口。面板只读后端继续复用核心打印控制，不维护相互冲突的成功判定。
