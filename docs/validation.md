## 可复跑检查

```powershell
python -B -m unittest discover -s tests -v
python -B -m compileall -q -x '(build|dist|\.git)' .
./scripts/build.ps1
dist\PrintBridge.exe --data-dir "D:\PrintBridgeSmoke" --smoke-test
python scripts/build_release.py dist/PrintBridge-v1.2.0-source.zip
```

GUI烟测需要显式隔离数据目录；输出smoke.json的ok/monitor_running/stopped应为true、wechat_started为false。它实际创建并绘制窗口、启动只读监控、通过Tk事件循环退出；不将该结果当成物理纸张或微信消息送达证明。

## 覆盖的失败模式

- 损坏配置不覆盖原件，原子替换失败不修改内存或磁盘状态，迁移中断不发布半文件；单实例锁跨进程保持。
- 打印历史行按唯一身份隔离设备及重复作业ID；缺纸、脱机和错误可恢复；终态观察在DB暂时失败后重试，终态不倒退；切换设备不重复插入同一作业。
- 单次EnumJobs完整快照避免分页offset随队列变化漏作业；句柄由调用线程关闭，驱动阻塞期间不从另一线程强关；COMPLETE不当作PRINTED。
- 微信首次基线不执行旧消息，出站文字写入失败或读回不一致时不按回车，操作前复核授权/类型/目标；已开始发送但结果未知时禁止自动重试。真实UI匹配与投递仍待客户端实测。
- CLI输出单个JSON并返回失败码，裸文件名歧义不会静默打印；读配置不创建文件，搜索不会无界遍历。
- GUI队列消费有预算，身份/筛选/状态计数/空态保持一致；设置保存不扩大扩展名授权；关闭窗口清理回调，托盘失败不隐藏成无法恢复的窗口。
- 面板读取失败标识旧数据，控制使用任务所属设备，隐藏和退出不在Tk线程等待驱动；面板只读显示不另写历史或发通知。
- 发布ZIP验证真实成员、逐文件校验和、同环境字节复现与禁止覆盖输入，拒绝运行数据；EXE不承诺字节复现。

## 界面核验

浅色工作台、三个设置页、桌面完整卡片和任务栏条使用合成数据做真实Tk渲染。检查默认及最小窗口、长设备/文档名、高DPI、无任务/无匹配结果和按钮禁用状态。README中的界面图为合成数据示例；其余核验图只在任务期间使用。

## 未验证边界

没有执行真实纸张打印、Office/PDF文件关联应用的端到端打印或微信客户端消息发送。ShellExecute返回成功只表示发起文件关联请求，驱动PRINTED仍取决于驱动对结束状态的支持。自动微信附件收件尚无可靠来源绑定，界面将其标为暂不可用。

托盘已随真实程序创建与停止，但Explorer重启后的图标恢复、不同厂商驱动、远程打印服务器和多显示器/不同缩放组合未穷尽验证。Windows CI验证代码与构建/冻结入口，不代表外部设备已验收。
